# AWS Services Used

## Amazon Route53

Purpose:

DNS Management

Responsibilities:

* Domain resolution
* Routing policies
* Health checks

---

## Application Load Balancer

Purpose:

Traffic distribution.

Responsibilities:

* Load balancing
* SSL termination
* Health monitoring

Benefits:

Improved availability and fault tolerance.

---

## Auto Scaling Group

Purpose:

Automatic instance scaling.

Capabilities:

* Scale out
* Scale in
* Self-healing

The group continuously maintains desired capacity.

---

## Amazon EC2

Purpose:

Application hosting.

Responsibilities:

* Application runtime
* Docker execution
* Nginx hosting

---

## IAM

Purpose:

Access control.

Responsibilities:

* Role management
* Permission boundaries
* Least privilege enforcement

---

## CloudWatch

Purpose:

Observability.

Metrics monitored:

* CPU
* Memory
* Network
* Disk
* Status checks

---

## SNS

Purpose:

Notification delivery.

Channels:

* Email
* SMS
* Operations alerts

---

## VPC

Purpose:

Network isolation.

Components:

* Public Subnets
* Private Subnets
* Route Tables
* Internet Gateway
* Security Groups

The VPC acts as the security boundary for the solution.
